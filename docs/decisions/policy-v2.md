# Policy Middleware v2 决策

## 决策

命令策略采用三段式风险模型：安全命令直接允许，需审查命令交给 `approval_callback`，危险命令直接拒绝。当前只实现策略和离线假工具，不开放宿主机任意 Shell。

## 原因

Baseline 当前只提供固定的 `run_tests` 工具，没有真实任意命令入口。先实现策略契约和 Agent 图集成测试，可以验证生命周期和拒绝行为，同时避免为了测试策略而扩大系统权限。

## 后续约束

如果以后加入真实命令工具，必须继续使用参数化进程调用、工作区 cwd、超时和输出上限，并在策略之外配置操作系统级隔离。仅通过 `classify_command()` 不能把宿主机 Shell 变成安全沙箱。
